# 🏏 NPL Paper Draw System

A simple HTML-based system to generate a **cricket tournament match schedule** using a paper draw method.

## 📌 Features

* Enter paper draw numbers (1–4)
* Automatically assign teams
* Generate **Round Robin match schedule**
* Display matches in **Round 1, Round 2, Round 3 layout**
* Print the match schedule
* Simple **HTML, CSS, JavaScript**

## 🏆 Tournament Format

Teams:

* SalesPlay
* Nvision
* Monyfi
* MediaX

Match System:

* Round Robin
* Each team plays against every other team once
* Total matches: **6**

Rounds:

Round 1
Match 1 – Team A vs Team B
Match 2 – Team C vs Team D

Round 2
Match 3 – Team B vs Team C
Match 4 – Team A vs Team D

Round 3
Match 5 – Team A vs Team C
Match 6 – Team D vs Team B

Top **2 teams from the points table** will qualify for the **Final match**.

## 🚀 How to Use

1. Open the `index.html` file in a browser
2. Enter the **paper draw numbers**
3. Click **Generate Teams**
4. The system will create the **match schedule**
5. Click **Print Match Schedule** to print or save as PDF
